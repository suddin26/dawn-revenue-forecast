How the forecast and adjustment work

Uniform scenario: base × (1 + adjustment / 100). Compounded scenario: base × (1 + adjustment / 100)horizon. Horizon is 1, 2, or 3 from the forecast origin—even if you hide earlier years.

Percentages multiply signed revenue. A positive percentage makes a negative revenue amount more negative. Historical gaps stay missing. Selections without cutoff-year records have no forecast.

Holt uses a damped trend; random forest uses two revenue lags and time; Monte Carlo samples recent annual dollar changes. P10–P90, shown only for a selected Monte Carlo forecast, is an assumption-based simulation range for the unadjusted projection.
